# 物探数据银行前端工程

React + TypeScript + Vite 本地演示工程，按最新 Sketch 拆成真实组件。文字、表格、表单、弹窗和操作图标都是 DOM / SVG；地图与 Logo 是独立资源。

## 用 VS Code 打开

打开本目录中的 `geobank-frontend.code-workspace`。使用 Node.js 22.13 或更高版本，在 VS Code 终端运行：

```sh
npm ci
npm run dev
```

打开终端显示的 `http://127.0.0.1:5173/`。首次访问先显示演示登录页，使用 `Demo / demo123` 登录，默认管理员；独立演示入口：

- 管理员：`http://127.0.0.1:5173/admin.html`
- 普通用户：`http://127.0.0.1:5173/ordinary.html`

首次安装依赖需要网络。安装完成后，页面数据和资源都可离线运行。开发服务器只监听本机。关闭终端任务可停止服务。

## 命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 开发与热更新 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run test` | 190 项组件与布局交互测试 |
| `npm run build` | 生成 `dist` 生产构建 |
| `npm run preview` | 本地查看构建结果，默认端口 4173 |

构建文件位于 `dist`。请通过静态 HTTP 服务查看，不能直接双击 `dist/index.html` 运行模块脚本。无需安装依赖的旧版完整交互画板 HTML 另行交付。

## 页面与状态

Hash 路由支持刷新、前进及后退。例如 `#/overview`、`#/results/current`、`#/results/current/wells`、`#/search`、`#/approval/approved`、`#/baseline/types`。会话内保存角色、当前项目、检索条件、审批筛选、右侧最大化和活动标签；退出并演示登录后恢复来源页面。不同入口的 `role` 参数优先于缓存角色。

| 目录 | 内容 |
| --- | --- |
| `src/pages` | 概览、成果、检索、审批、基准、登录页面组件 |
| `src/components` | 导航与 Demo 菜单、对话框、地图控件 |
| `src/services` | 本地数据、查询、权限、演示登录、编辑/导入/上传/基准保存；接入接口时从此层替换 |
| `src/data` | 原 Sketch 的六个项目与两条检索样例 |
| `src/App.tsx` | 统一页面状态、Hash 路由及项目访问守卫 |
| `public/assets` | 独立地图图片和 Logo |

## 演示约定

- 原六个项目的状态与权限保持：0/1/3 未归档且可查阅，2/4/5 已归档且无查阅权限。普通用户仅见三个已归档项目，查阅会提示“您无浏览此项目数据的权限”。没有补造普通用户可成功查阅样例。两个检索样例均未归档，因此普通用户检索为空。
- 检索支持同组连续多选；候选数量保留其他组及关键词限制，不受本组已选项限制。已选零结果条件仍可取消；“清空”只清复选条件。
- 地图项目详情跟随项目标记浮动，靠边自动避让；地图点击保持当前视野，列表定位保留镜头定位。卡片展示归档状态、项目概况、处理参数与关联项目；首个项目的补充参数来自原 Sketch，其他缺失数据保持空态。
- 顶部支持中英文切换，语言选择保留在当前浏览器会话；项目名、文件名等业务数据保持原文。成果页支持拖拽调整三栏宽度，保留各布局滚动位置。
- 右侧成果视图最大化时隐藏顶部“上传成果”，项目选择框填满左侧；默认分屏及项目信息最大化时仍显示。测井等目录中的“上传文件”仅含本地、远程两项。上传只写入本地演示的文件元数据，远程目录使用已有样例，Excel 导入回填预设字段，不解析或发送真实文件。
- Demo 登录账号：`Demo / demo123`。菜单支持 Esc、点击外部收起，`Alt Q` 退出；输入框或弹窗期间不触发快捷键。密码只存在于输入组件内，不保存。
- AI 总结、本地增删改、扫描、审批提交均为演示；没有连接业务接口、真实认证或远程服务。重新加载会重置部分演示业务列表，页面条件保留在当前浏览器会话。
- 统计以及未设计的审批空白栏目保持空白。基准项目类型沿用最新 Sketch 的“名称、颜色、操作”三列。结果文件扩展字段缺少设计明细，保持摘要与空态。

验收详情见同批交付的 `验收与启动说明.md`。
